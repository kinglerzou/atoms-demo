# Atoms Studio Demo

包含完整滚动首页和可运行的 AI 应用生成工作台，参考 Atoms 中文首页以及其“自然语言 → 团队规划 → 代码生成 → 可视化预览 → 对话迭代”核心流程。不是 Atoms 商业站全站克隆，也不包含其账户、支付、云数据库或广告平台。

## 快速启动

要求 Node.js >= 22.13（推荐 Node.js 24）。

```bash
npm install
cp .env.example .dev.vars
# 编辑 .dev.vars，填写 OPENAI_API_KEY
npm run dev
```

打开终端显示的本地地址。项目已经预留空白 `.dev.vars`，可直接填写；该文件被 Git 忽略。

```dotenv
OPENAI_API_KEY=
OPENAI_BASE_URL=https://api.openai.com/v1
OPENAI_MODEL=gpt-5.5
```

- 模型名可替换为账号可用、支持 Responses API 的模型。
- `OPENAI_BASE_URL` 是包含 `/v1` 的服务基地址，服务端添加 `/responses`。
- 修改本地变量后重启服务。线上在托管平台填写同名环境变量并重新部署。
- 密钥仅用于服务端请求，不传到前端，不放入 NEXT_PUBLIC 环境变量。
- 没有密钥时：模板、项目管理、预览、代码编辑、版本历史、导入导出仍可使用；真实 AI 生成明确提示未配置，不伪造生成结果。

## 架构

- React 19 + TypeScript + Vinext，Cloudflare Workers 兼容的服务端路由。
- `app/page.tsx`、`app/landing.css`：官网风格的完整滚动首页。
- `app/studio/page.tsx`：工作台、项目和版本管理。
- `lib/showcases.ts`：六套可交互案例。
- `lib/landing-data.ts`：团队、功能、套餐及 FAQ 内容。
- `app/globals.css`：响应式样式。
- `app/api/generate/route.ts`：服务端环境配置入口。
- `lib/generation.ts`：两个顺序模型调用与 NDJSON 阶段流。
- `lib/templates.ts`：三套独立、可交互的内置模板。
- `tests/generation.test.ts`：接口验证和模拟上游流程测试。

真实 AI 流程有两次模型调用（规划、构建），最后执行确定性的 HTML 完整性检查。UI 不将该检查描述为完整自动测试。内置模板明确标注为示例，绝不冒充模型输出。

预览只授予 `allow-scripts allow-forms`（本地表单事件，CSP 仍禁止网络提交），不授予 `allow-same-origin`。CSP 禁止网络请求、外部脚本、表单提交。使用受限 `postMessage` 存储桥接；父页面只接收当前 iframe 消息，限制数据类型及大小。应用脚本不能访问宿主页的 localStorage。导出 HTML 以本地 localStorage 持久化其数据。

数据仅保存在当前浏览器、当前站点，不跨设备同步。清除浏览器数据前请导出 JSON 备份。版本回退恢复代码，不回退运行中的业务数据。

## 手动验收路线

1. 首页选择 Focus 模板；添加任务、勾选完成、切换筛选。
2. 刷新整个浏览器，再打开项目，确认任务仍然存在。
3. 切换手机预览，进入代码页改标题并保存，查看新增版本。
4. 历史中恢复初始版本，确认保留两个旧版本并新增恢复版本。
5. 重命名、搜索、复制项目；导出 HTML，在独立浏览器中打开。
6. 设置中备份全部项目，再恢复备份，确认不会覆盖原有数据。
7. 未配置模型时发送需求，应提示配置，不应生成虚假结果。
8. 配置 `.dev.vars` 后重启，生成应用并发送二次修改需求，观察规划/构建/检查状态。
9. 生成中停止，确认旧版本不丢失；错误密钥应给出认证错误。

## 交付边界

这是可扩展的单页应用生成原型。公开开放模型接口前，应增加访问控制、额度及速率限制；当前 Sites 部署保持默认私有。生成应用内的支付、邮件或远程数据能力不能靠单 HTML 自动获得，需另行配置对应后端。模板联系表单只本地保存，不发送邮件。

## 部署到自己的 Cloudflare Workers

使用已安装的 Wrangler，先在 Cloudflare 账号中确认 Workers Free 套餐。

```bash
npx wrangler login
npm run build
npx wrangler deploy --config wrangler.cloudflare.json
node scripts/cloudflare-secrets.mjs
```

最后一条命令仅从本机被 Git 忽略的 `.dev.vars` 读取 `OPENAI_API_KEY`、`OPENAI_BASE_URL`、`OPENAI_MODEL`，通过标准输入直接发送到 Cloudflare Secrets，不打印参数内容。该操作需要事先登录并完成首次部署。

部署后使用 Wrangler 返回的 `workers.dev` 地址。后续在 Cloudflare 控制台的 Workers & Pages → atoms-demo → Settings → Variables and Secrets 可管理配置。模型服务商需支持 Responses API，模型费用独立于 Cloudflare 托管费用。免费套餐资源不足时应先诊断，不要自动升级付费。
